gRPC

Yêu cầu gRPC Client

Bài tập này sử dụng giao thức gRPC và không thể thực hiện trực tiếp trên trình duyệt web.

Bạn cần sử dụng gRPC client (ví dụ: grpcurl hoặc Java gRPC client) để kết nối đến server qua port 2240.

Ví dụ grpcurl:
grpcurl -plaintext localhost:2240 JudgeService/getData

Yêu cầu SOAP Client

Bài tập này sử dụng giao thức SOAP và không thể thực hiện trực tiếp trên trình duyệt web.

Bạn cần sử dụng SOAP client (ví dụ: soapui, Postman, hoặc Java SOAP client) để gửi SOAP request.

WSDL Endpoint:
http://localhost:2230/ws/data.wsdl
http://localhost:2230/ws/character.wsdl
http://localhost:2230/ws/object.wsdl
